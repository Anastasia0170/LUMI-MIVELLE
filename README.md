## GitHub Pages
1. Створіть публічний репозиторій на GitHub.
2. Розпакуйте ZIP та завантажте весь його вміст у корінь репозиторію (index.html має бути в корені, папка assets — поруч).
3. Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save.
4. Після публікації відкрийте адресу, яку покаже GitHub Pages.

Для локальної перевірки можна запустити `python -m http.server 8000` у папці сайту та відкрити http://localhost:8000.

Каталог, обране, кошик та калькулятор працюють у браузері; кошик і обране зберігаються в localStorage. Форма завантажує локальний текстовий файл, не надсилає заявку. Немає платежів, сервера чи реальних контактів бренду. Ціни демонстраційні, ілюстрації — оригінальні SVG-концепти, не фотографії. Відгуки не вигадані. Для реального запуску потрібні підтверджені контакти, ціни, правила продажу та канал приймання заявок.

Каталог: 70 демонстраційних позицій, по 10 у кожній з 7 категорій. Зображення — згенеровані концепти, ціни орієнтовні.
